# Misión Órbita 

Simulador de exploración espacial en consola, desarrollado en Python para el curso **SOFT-01 Principios de Programación 1** (Universidad CENFOTEC).

El programa planifica una misión espacial: calcula los recursos necesarios, autoriza el lanzamiento, simula el viaje día a día, permite realizar actividades de exploración científica en el destino y evalúa si la tripulación puede regresar a la Tierra o queda varada.

## Integrante
- Deylan Tencio

## Requisitos
- Python 3.10 o superior.

## Cómo ejecutar
Desde la carpeta raíz del repositorio, ejecute el ejercicio deseado:

```bash
# Avance 1: preparación de la misión
python avance1/ejercicio1_recursos.py
python avance1/ejercicio2_combustible.py
python avance1/ejercicio3_soporte_tripulacion.py
python avance1/ejercicio4_autorizacion.py

# Avance 2: ejecución de la misión
python avance2/ejercicio5_destino.py
python avance2/ejercicio6_viaje.py
python avance2/ejercicio7_exploracion.py
python avance2/ejercicio8_regreso.py
```

Cada programa solicita los datos por consola; ingrese números enteros positivos cuando se le pidan.
